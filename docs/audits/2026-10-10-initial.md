## 1. Resumen ejecutivo

**Justina.io** es el MVP de una hackatón de No Country (2024): plataforma de gestión médica orientada a pacientes trasplantados (pacientes, doctores, turnos, tratamientos, recetas, medicamentos, laboratorios, financiadores, instituciones). Monorepo `client/` (React 18 + Vite 5 + Tailwind 3, JS) y `server/` (Spring Boot 3.3.1, Java 17, JPA, JWT, PostgreSQL/MySQL).

**Estado:** compila y corre en local con una base PostgreSQL, y el login funciona por rol de punta a punta **si** se redirige la URL del back (hoy está hardcodeada a producción). No hay tests reales (1 `contextLoads` que falla sin DB), no hay CI, y hay **fallas de seguridad críticas** (registro de ADMIN público, sin autorización por rol). Gran parte del front usa datos mock.
